# Orbit – Startup Landing Page (concept)

Responsive landing page for a fictional startup. Plain HTML, CSS and JavaScript. No build step, no backend.

## Run locally
Open `index.html` in any browser. Or serve the folder:

```
py -m http.server 8000
```
then visit http://localhost:8000

## Files
- `index.html` page structure and content
- `styles.css` design tokens (colors in `:root`), layout, responsive rules
- `script.js` demo email sign-up validation

## Customise
- Change colors in the `:root` block at the top of `styles.css`
- Edit text directly in `index.html`
- Connect the sign-up form to your email tool (Mailchimp, ConvertKit, etc.) in `script.js`

## Deploy
Drag the folder onto Netlify Drop, or push to GitHub and enable GitHub Pages.
